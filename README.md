# detecta-fraude — Rinha de Backend 2026

Submissão para a [Rinha de Backend 2026](https://github.com/zanfranceschi/rinha-de-backend-2026), o desafio de detecção de fraude por busca vetorial.

Stack: `rust` + `c`, kd-tree particionada, `SCM_RIGHTS`, `epoll`, `AVX2`.

## Documentação

- [Arquitetura](docs/ARQUITETURA.md) — visão geral, topologia, pipeline de vetorização, layout do índice e os algoritmos de busca kNN (com diagramas).
- [Decisões técnicas](docs/DECISOES_TECNICAS.md) — o porquê de cada escolha, amarrado à fórmula de pontuação da Rinha (p99 e detecção).
